## Co to jsou GitHub Actions?

GitHub Actions jsou funkcionalitou GitHubu, platformy na hostování Git repozitářů, k automatickému spouštění skriptů, testů, buildů a nasazování aplikace. To s pomocí jednoduché konfigurace pomocí YAML souborů a integrací s GitHubem a dalšími aplikace a službami.

## Jak školení probíhá

Školení GitHub Actions probíhá formou workshopu, kde si poslečně vše vyzkoušíme, od psaní jednoduchých workflows (pipeline), až po tvorbu vlastních actions šití vlastních řešení na míru vašim potřebám.

## Co Vás naučím

- Úvod do CI a automatizace v GitHubu
- Práci a psaní vlasních workflows (pipeline)
- Práci a psaní vlastních actions (základní stavební bloky)
- Testování akctions a workflows
- Best practices

## Pro koho je školení určeno

Školení je primárně určeno lidem, kteří nemají žádné (nebo malé) zkušenosti s automatizací pomocí CI pipeline v GitHubu — GitHub Actions. Školení nepočítá s předchozí znalostí CI a je vhodné jak pro vývojáře nebo DevOps (server administrátory), kteří si chtějí usnadnit život automatizací nebo zvýšit spolehlivost aplikací.

Školení je nezávislé verzi GitHubu, kterou používáte. Ať máte vlastní účet zdarma, firemní organizaci nebo GitHub Enterprise Cloud případně Enterprise Sever.
