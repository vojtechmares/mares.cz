## What Is Terraform and What Is It Used For?

Terraform is a tool used to manage infrastructure in the cloud, both public (AWS, Azure, GCP) and private (OpenStack, VMware vSphere).

Terraform lets you manage infrastructure as code — versioned in Git, adding resources through merge (pull) requests, and many other benefits. You can deploy infrastructure to a test environment exactly as it is in production without extra effort. You have visibility into all components and can predict costs. No more clicking through infrastructure — try Terraform.

Terraform also supports managing multiple cloud providers simultaneously and working with hybrid clouds (part in a private cloud, part in a public cloud).

## How the Training Works

The training is a hands-on workshop — we will try everything out in detail and explain it thoroughly. We will show how Terraform works, how to use it in a team, and how to manage infrastructure with it. We will build an example infrastructure for a simple application, setting up everything — from DNS, through a Kubernetes cluster, to S3 file storage.
