## What Is CloudNativePG?

CloudNativePG (CNPG for short) is a Kubernetes Operator for PostgreSQL.

The CNPG operator manages the full lifecycle of PostgreSQL clusters running on Kubernetes (for the advanced: operator level 5 — autopilot). CNPG also brings many additional features, such as:

- Automatic backups
- Automatic replication (primary, synchronous, and asynchronous replicas)
- Automatic failover
- Restore from backup
- Point In Time Recovery (PITR)
- pgBouncer integration (connection pooling)
- Prometheus integration (monitoring)
- Read-only replicas
- Replica cluster (in a different Kubernetes cluster)
- kubectl plugin
