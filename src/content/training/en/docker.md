## What Is Docker?

Docker is a technology that greatly simplifies the process of developing, testing, and running software. Run anything, anywhere. Stop waiting for your server to be configured or for some library to be updated. Make the environment a part of your application.

## How the Training Works

In the Introduction to Docker training, we will cover everything from creating your own containers to running them on a server. Everything will be hands-on — you will try it all out for yourself.

## What You Will Learn

- Theoretical introduction to Docker
- Docker installation (for those who haven't installed it at home)
- Working with containers
- Working with images
- Docker Compose — multi-container applications in Docker

## Who Is This Training For

This training is primarily designed for people who have no (or little) experience with Docker. The training does not assume any prior Docker knowledge. It is suitable for developers or DevOps engineers (server administrators) who want to use Docker in practice or want to understand what Docker solves and where they could use it.

### Prerequisites

- Basic Linux skills
- Basic terminal skills

### Technical Requirements

- Docker installed
- Internet access — ideally without a corporate proxy, or with proxy configured in the browser
