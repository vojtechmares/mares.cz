## Technology Overview

Kubernetes is today's most widely used platform for hosting Docker containers, supported by major players in the market (Google, Amazon, Microsoft) through the Cloud Native Computing Foundation. Companies of all sizes use Kubernetes in production, from startups to enterprises.

## How the Training Works

The training is a hands-on workshop — we will try everything out in practice. We will show how to run Kubernetes locally (for development) and on the DigitalOcean cloud platform. We will learn the basic Kubernetes architecture and go through its components. We will learn how to write Kubernetes manifests and deploy Docker applications using them. We will also cover how to work with permissions in Kubernetes and how to use (and write) Kubernetes packages with Helm.

### What You Will Learn

- Theoretical introduction to Kubernetes
- Installing Minikube and kubectl (for those who haven't installed them at home)
- Overview of Kubernetes components
- Deployment to Kubernetes
- Working with permissions in a Kubernetes cluster
- Theoretical introduction to Helm packages
- Installation / Deployment using Helm
- Writing your own Helm package

### Who Is This Training For

This training is designed for people (developers and DevOps engineers) who want to run their Docker applications in Kubernetes.

### Prerequisites

- Basic Docker skills
- Basic Linux skills
- Basic terminal skills

### Technical Requirements

- Internet access — ideally without a corporate proxy, or with proxy configured in the browser
