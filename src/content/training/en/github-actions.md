## What Are GitHub Actions?

GitHub Actions is a feature of GitHub, the platform for hosting Git repositories, for automatically running scripts, tests, builds, and application deployments. All through simple YAML configuration files and integrations with GitHub and other applications and services.

## How the Training Works

The GitHub Actions training is a hands-on workshop where we will try everything together — from writing simple workflows (pipelines) to creating custom actions tailored to your specific needs.

## What You Will Learn

- Introduction to CI and automation on GitHub
- Writing your own workflows (pipelines)
- Writing your own actions (fundamental building blocks)
- Testing actions and workflows
- Best practices

## Who Is This Training For

This training is primarily designed for people who have no (or little) experience with CI pipeline automation on GitHub — GitHub Actions. The training does not assume prior CI knowledge and is suitable for developers or DevOps engineers (server administrators) who want to simplify their lives through automation or increase application reliability.

The training is independent of the GitHub version you use. Whether you have a free personal account, a company organization, or GitHub Enterprise Cloud or Enterprise Server.

### Prerequisites

- Basic Linux skills
- Basic terminal skills

### Technical Requirements

- Git installed
- Internet access — ideally without a corporate proxy, or with proxy configured in the browser
- Your own account on [GitHub.com](https://github.com/)
