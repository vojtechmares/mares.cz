**GitHub Actions training**

Mr. Mareš provided us with excellent training on pipelines, CI/CD, and hands-on demonstrations with real-life examples based on his extensive experience in DevOps. We have both senior DevOps people and beginners on our team, and the content and format of his training was suitable for both groups -- thumbs up.

**Git & GitHub training**

We learned a great deal about how Git works under the hood, with real demonstrations of operations (including less common ones) both in the command line and in tools like GitHub Desktop. It was useful to see the most efficient ways to work with Git and how it all fits into our team's daily workflow through GitHub Enterprise, which we use at our company.
