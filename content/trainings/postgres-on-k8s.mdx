# Co je to CloudNativePG?

CloudNativePG (zkráceně CNPG) je tzv. Kubernetes Operator pro PostgreSQL.

CNPG operátor se stará o PostgreSQL clusterů běžících na Kubernetes. A to o celý životní cyklus clusteru (pro pokročilé: operator level 5: autopilot).
CNPG zároveň přináší spoustu dalších funkcní, jako například:

- Automatické zálohování
- Automatické replikaci (primary, synchronní i asynchronní replika)
- Automatický failover
- Obnovení ze zálohy
- Point In Time Recovery (PITR)
- pgBouncer integraci (connection pooling)
- Prometheus integraci (monitoring)
- Read-only repliky
- Replika cluster (v jiném Kubernetes clusteru)
- `kubectl` plugin
